## /prompt Command

Quand l'utilisateur tape `/prompt`, tu dois :

1. Analyser le contexte actuel du projet et les tâches en cours
2. Lire les documents de référence (/docs/PROJECT.md, /docs/MAP_STATUS.md, /docs/MAP_REFACTORING_PLAN.md)
3. Rédiger un prompt complet et structuré pour un nouvel assistant Windsurf
4. Ce prompt doit inclure :
    - Le contexte complet du projet
    - Les tâches à réaliser (prochaines phases)
    - Les processus à suivre
    - Les fichiers clés à consulter
    - Les pièges à éviter
    - Les règles de validation et documentation
