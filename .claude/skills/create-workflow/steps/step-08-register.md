### 2. Update CLAUDE.md

**Find workflows section in CLAUDE.md:**

Search for existing workflow tables like:
```markdown
## Workflows Disponibles
```
or
```markdown
| Workflow | Quand l'utiliser |
```

**Add new workflow entry:**

Determine appropriate section:
- Development workflows → under "Developper"
- Creation workflows → under "Creer"
- Utility workflows → under "Utilitaires"

**Entry format:**
```markdown
| `/{workflow_name}` | {brief_description} |
```

**If no workflows section exists:**

Create one:
```markdown
## Workflows

| Workflow | Description |
|----------|-------------|
| `/{workflow_name}` | {brief_description} |
```

**Apply edit:**
```
Use Edit tool to add the new entry
Verify the edit was successful
```

---

### 3. Update SYSTEM.md (if applicable)

**Check if workflow is system-level:**

System-level indicators:
- Affects other workflows
- Part of core development process
- Referenced by multiple other skills

**If system-level:**
```
Read .claude/context/SYSTEM.md
Find appropriate section
Add workflow documentation
```

**Standard workflows do NOT need SYSTEM.md update.**

---
