# Step 03: Synthesize

> Generer le rapport de securite structure.

---

## Task

Creer un rapport complet avec:
1. Executive Summary
2. Findings par severite
3. Roadmap de remediation
4. Annexes techniques

---

## Execution

### 1. Calculer les Stats

```yaml
stats:
  total_findings: {count}
  by_severity:
    critical: X
    high: Y
    medium: Z
    low: W
  by_category:
    injection: N
    auth: N
    config: N
    deps: N
  total_effort: {sum of story points}
  estimated_sprints: {total_effort / 20}  # ~20 points/sprint
```

### 2. Generer le Rapport

Utiliser le template `templates/security-report.md` et remplir:

```markdown
# Security Audit Report

> **Date**: {today}
> **Project**: {project_name}
> **Stack**: {stack.type}
> **Mode**: {mode}
> **Scope**: {scope}

---
