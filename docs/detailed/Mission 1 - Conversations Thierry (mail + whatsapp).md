    ## **PHOTOS & REELS - Mode Invité dans l'App**
    
    ![📸](https://fonts.gstatic.com/s/e/notoemoji/16.0/1f4f8/72.png)

    2. **L'invité scanne** ou tap sur le lien → Deep link qui ouvre l'App Store/Play Store si pas installé, puis l'app avec le code mariage pré-rempli (chaque mariage aura un code définit donc on pourra aussi le taper à la mains mais moins pratique)

        - Chat de groupe avec tous les invités + la mariée
        - Acheter son propre reel (généré depuis SES vidéos uniquement comme tu l’as demandé, ou plus tard toutes)

    - Une seule codebase (pas de webapp à maintenir)

        ![✅](https://fonts.gstatic.com/s/e/notoemoji/16.0/2705/72.png)

        ![✅](https://fonts.gstatic.com/s/e/notoemoji/16.0/2705/72.png)
